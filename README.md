## 人員操作

選擇工編 → 填姓名／員編 → 選填起迄日 → 輸入使用時數 → 確認送出。

- 顯示每個可掛列工編扣除預留後的可用時數（總額度－已掛列－預留）。已刪除、結案、停用、用罄的工編不列入選單。
- 可用時數大於 0 且不超過 16 小時時，選單及餘額下方會提醒「僅可掛列正常工時」，不受管理員手動編輯工作項目名稱影響。
- 起迄日選填，沒有七天或兩週限制；迄日不得早於起日。
- 工時最小單位為 0.25 小時，加減按鈕每次調整 1 小時。
- 掛列時間由伺服器記錄；超額整筆攔截、同筆重試不會重複扣抵。
- 送出紀錄與後台明細、額度及 CSV 同步。
- 有預留工時的工編達預留底線時會自動結案，已結案工編不接受新掛列。

## 修改與發布

可修改的畫面放在 `source/index.html`。不需安裝套件，使用 Node.js 22.13 以上：

```sh
cd source
npm run build
```

建置會更新根目錄的管理入口及 `v2/index.html`。將更新提交到 main 後，GitHub Pages 會自 main 根目錄自動發布。

GitHub 保存前端程式；正式工時與權限保存在原後台 D1，沒有將工時紀錄放入儲存庫。測試工編與測試紀錄分開保留，不會覆蓋正式資料。
